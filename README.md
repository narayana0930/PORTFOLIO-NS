## 🌐 How to Host It Online for Free on GitHub Pages (Takes 2 Minutes)

To get a live public link like `https://narayanasamygithub.github.io` for your resume and LinkedIn:

1. **Log in to your GitHub account** ([github.com](https://github.com)).
2. Click **New Repository**:
   - Repository name: `portfolio` (or `narayanasamygithub.github.io`).
   - Set it to **Public**.
3. **Upload the files**:
   - Click **Add file** > **Upload files**.
   - Drag and drop:
     - `index.html`
     - The `assets/` folder (with `css/style.css` and `js/main.js`).
   - Click **Commit changes**.
4. **Enable GitHub Pages**:
   - Go to repository **Settings** > **Pages** (on the left menu).
   - Under *Build and deployment*, set Source to **Deploy from a branch**.
   - Select Branch: `main`, Folder: `/ (root)`, and click **Save**.
5. Within 60 seconds, your site will be live at:
   `https://<your-username>.github.io/portfolio`!
